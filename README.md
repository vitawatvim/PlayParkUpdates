# PlayPark Desktop Bot

พื้นที่ดาวน์โหลดโปรแกรมและอัปเดตอย่างเป็นทางการ ซอร์สโค้ดเก็บแยกใน repository ส่วนตัว

## ดาวน์โหลด

[ดาวน์โหลดเวอร์ชันล่าสุด](https://github.com/vitawatvim/PlayParkUpdates/releases/latest)

1. เลือกไฟล์ `PlayParkDesktopBot-<version>-windows.zip` ใน Assets
2. แตก ZIP ทั้งหมดลงในโฟลเดอร์ที่คุณมีสิทธิ์เขียน เช่น โฟลเดอร์ส่วนตัว
3. เปิด `PlayParkDesktopBot.exe` และเก็บโฟลเดอร์ `ms-playwright` ไว้ข้างกัน

ไม่ต้องติดตั้ง Python หรือมีบัญชี GitHub เพื่อดาวน์โหลด

## การอัปเดต

เวอร์ชัน 1.2.0 เป็นต้นไปตรวจอัปเดตเมื่อเปิดแอพ และมีปุ่มตรวจอัปเดตเอง
หากพบเวอร์ชันใหม่ กดดาวน์โหลดและอัปเดตเพื่อดู progress และให้แอพเปิดใหม่
ควรให้งานบอทเสร็จก่อนติดตั้ง บัญชีและการตั้งค่าในเครื่องจะคงเดิม

เวอร์ชันเก่าที่ยังไม่มีระบบอัปเดตต้องดาวน์โหลด ZIP และเปลี่ยนมาใช้เวอร์ชันนี้หนึ่งครั้งก่อน
ไฟล์ `update.json` และ `SHA256SUMS.txt` ใช้ตรวจสอบแพ็กเกจ ไม่ใช่ตัวเปิดโปรแกรม

แพ็กเกจมี Chromium รวมอยู่ด้วย จึงมีขนาดหลายร้อย MB และต้องมีพื้นที่ว่างสำหรับแตกไฟล์และสำรองเวอร์ชันเดิม
ไฟล์สำรอง `.playpark-backup-*` เก็บไว้ข้างโปรแกรมเพื่อกู้คืน ส่วนข้อมูลบัญชีเข้ารหัสเก็บใน LocalAppData ของผู้ใช้ Windows

รุ่นนี้คงวันหมดอายุเดิม: 31 ธันวาคม 2026 การอัปเดตไม่เปลี่ยนวันหมดอายุโดยอัตโนมัติ
แพ็กเกจอัปเดตตรวจลายเซ็นโดยแอพ แต่ยังไม่มีใบรับรองผู้เผยแพร่ Windows
